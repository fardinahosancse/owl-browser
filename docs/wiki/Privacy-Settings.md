# Privacy Settings

Everything is under **Menu > Settings**, grouped as Appearance, Security, Privacy, Downloads and data, Sync, and Profile and advanced.

| Setting | Default | Notes |
|---|---|---|
| Block trackers and ads | On | Host blocklist. Counters appear on the home page. |
| HTTPS-only mode | Off | Upgrades http to https and warns before plain http. |
| Fingerprint protection | On | Noise on canvas and audio; applies to new pages. |
| Strict fingerprint protection | Off | Same screen size, language and plugins for every site; may show English or odd layouts. |
| Strict tracking prevention | Off | Blocks third-party trackers and their storage; may break embedded logins and videos. |
| Block camera, microphone, location, notifications | Off | Refuses these requests silently. Sensors, fonts, MIDI and window management are always refused. |
| Check for new versions | Off | Asks GitHub once a day for the latest release tag. Notify only; skipped with a proxy. |
| Offer to save passwords | On | Asks after you sign in. |
| Lock when Windows locks or sleeps | On | Also seals data at shutdown. |
| Auto-lock | 15 minutes | Never, 5, 15, 30 minutes or 1 hour. |
| Proxy or VPN | Empty | For example `socks5://127.0.0.1:9050` for Tor. WebRTC is forced through it. |

## Tips

- Use a long passphrase (several words). Change it under Security.
- For maximum privacy: turn on strict tracking prevention, HTTPS-only and the permission block, and use private windows for sensitive browsing.
- A proxy such as Tor hides your address from sites, and Owl skips the update check while it is set.

# Getting Started

## First run

1. A **Welcome** screen asks for your name, email and a new passphrase (12 or more characters). Your name and email stay on this PC inside the encrypted store and are never sent anywhere.
2. Owl opens to the home page: clock, search, quick access, bookmark groups, time-online and privacy statistics.
3. Open **Menu > Settings** to choose a theme, set auto-lock, a proxy, sync and more.

**Remember your passphrase.** It is the root of everything Owl encrypts. There is no reset: if it is lost, sealed data cannot be recovered.

## The layout

- **Footer toolbar:** tabs on the left, address bar and tools in the middle, window controls on the right. The page gets every other pixel.
- **Address bar:** type a search or an address. A lock shows for https pages and "Not secure" for plain http.
- **Star:** bookmarks the page in your last-used group, with an Undo notice and a way to change the group.
- **Menu:** history, downloads, bookmarks, passwords, private window, themes, settings, lock.

## Tabs

Drag to reorder. Right-click (or the Menu key) for pin, mute, duplicate and close. Use the arrow keys, Home, End and Delete when a tab has focus.

## Locking

Press `Ctrl+Shift+L`, or let auto-lock do it. Locking closes every page and seals your cookies, logins and site data. Unlock with your passphrase and your tabs come back.

## Private windows

**Menu > Private window** opens a window that saves nothing and uses a temporary data folder that is removed afterwards.

## Command line

```
Owl.exe https://example.com     open a start page
Owl.exe --private               private window
```

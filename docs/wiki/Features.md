# Features

## Browsing

- Tabs with drag reorder, pin, mute, duplicate and a right-click menu.
- Bookmarks with groups and an optional bookmark bar (`Ctrl+B`), full keyboard access.
- History with day groups, search, per-item remove and a confirmed Clear.
- Find in page with previous, next and close.
- Zoom, full screen, session restore, developer tools (`F12`).
- Start URL from the command line.

## Home page

Clock, search, quick access tiles, bookmark groups, time-online and tracker-blocking statistics, downloads and shortcuts.

## Downloads

Progress, combined speed, pause, resume, cancel, retry, folder sorting (Documents, Images, Video, Music, Archives, Programs) and an approval step for risky or unexpected downloads.

## Passwords

Capture on sign-in, click-to-fill and a generator. Passwords are bound to your passphrase. See [Security Model](Security-Model).

## Media

A now-playing widget controls music and video playing in another tab, with per-tab audio and mute.

## Themes

System, Light, Dark, Black, Navy, Invert, Sand and Random. Motion respects the system "reduce motion" setting.

## Accessibility

Tabs, the bookmark bar and address suggestions work from the keyboard; switches and filters announce their state; dialogs trap focus; text contrast meets WCAG AA in the main themes.

## Sync

Optional: keep bookmarks, history and open tabs in a folder synced by OneDrive, Dropbox or Syncthing, encrypted with a sync passphrase.

## Extensions

Drop `.js` files in `%LOCALAPPDATA%\Owl\extensions` and they run on every web page (user scripts).

# Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close tab |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `Ctrl+1` to `Ctrl+9` | Jump to tab |
| `Ctrl+L` | Address bar |
| `Ctrl+F` | Find in page |
| `Ctrl+D` | Bookmark (with Undo notice) |
| `Ctrl+B` | Bookmark bar |
| `Ctrl+H` | History |
| `Ctrl+R` / `F5` | Reload |
| `Alt+Left` / `Alt+Right` | Back / forward |
| `Ctrl` `+` `-` `0` | Zoom in, out, reset |
| `F11` | Full screen |
| `F12` | Developer tools (page tabs) |
| `Ctrl+Shift+L` | Lock Owl |

## On a focused tab

Arrow keys move between tabs, `Home` and `End` jump to the ends, `Delete` closes, and the Menu key opens the tab menu.

Shortcuts are ignored while a dialog is open.
